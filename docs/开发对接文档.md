### 限速概念解释

| 指标 | 全称 | 说明 |
| --- | --- | --- |
| 并发 | Concurrency | 同一时间内我们最多处理的来自您的请求数 |
| RPM | Requests Per Minute | 指一分钟内您最多向我们发起的请求数 |
| TPM | Tokens Per Minute | 指一分钟内您最多和我们交互的 token 数 |
| TPD | Tokens Per Day | 指一天内您最多和我们交互的 token 数 |

### 为什么要做限速？

速率限制是 API 接口的常见做法，主要有以下几个考量：

- **防止滥用**：有助于防止滥用或误用 API。例如，恶意行为者可能会通过大量请求来淹没 API，试图使其过载或导致服务中断。通过设置速率限制，我们可以防范这样的行为。
- **公平使用**：速率限制有助于确保每个人都能公平地访问 API。如果一个人或组织发出过多的请求，可能会拖慢所有人的 API。通过限制单个用户可以发出的请求数量，尽可能多的人有机会使用 API 而不会遇到速度减慢的问题。
- **负载管理**：速率限制可以帮助我们管理集群总负载。如果对 API 的请求急剧增加，可能会给服务器带来压力并导致性能问题。通过设置速率限制将可以帮助为所有用户维护一个平稳且一致的体验。

### 特别说明

我们将全力保障用户的正常使用，但当集群负载达到容量上限时，我们可能会采取临时的限流措施，对各类限速进行调整。代金券不计入累计充值总额。

## 峰谷定价（分时计费）

部分模型支持峰谷定价：一天划分为**峰、平、谷**三个时段，各时段适用各自的输入价/输出价（统一价模型为统一价）。上表「峰谷定价」列展示各模型当前的时段划分与价格，并标注**当前所处时段**。

- **计费规则**：按**请求开始时刻**所处时段计价，整单一价——流式请求跨过时段边界不拆分计费；视频任务按**提交时刻**的时段计价。
- **价格权重**（模型峰谷启用时）：用户单独峰谷价 > 统一峰谷价 > 用户定价 > 统一定价。
- **时段判定**：按北京时间；时段支持跨零点（如谷 23:00~07:00）；未明确覆盖的时间一律按「平」计价。
- **查询记录**：「用量记录」和导出的 Excel 中，「时段」列标注每笔消费所属的峰/平/谷；峰谷未启用（或历史记录）显示 -。
- **缓存命中**：命中缓存的 tokens 按现行缓存价格体系计费，折扣逻辑不受峰谷影响。

> 峰谷定价对模型开启后立即对新请求生效；关闭后立即恢复常规定价。计费以请求进门时定格的时段为准。

## 认证方式

所有 API 请求需要在 HTTP Header 中携带 API Key 进行认证。本平台支持以下两种认证方式：

### 方式一：Authorization Bearer（推荐）

**HEADER** `Authorization: Bearer <your_api_key>`

### 方式二：x-api-key

**HEADER** `x-api-key: <your_api_key>`

部分第三方工具（如 Claude Code、某些 IDE 插件）只支持 `x-api-key` 头部，可直接使用此方式认证，无需 `Bearer` 前缀。

API Key 可在本平台"API Keys"页面生成和管理。每个用户可以创建多个 API Key。

> ⚠️ 请勿将 API Key 硬编码在前端代码或公开仓库中，建议使用环境变量存储。

## 对话接口

**POST** `/v1/chat/completions`

发送对话消息，获取 AI 回复。支持流式和非流式两种模式。

### 请求体示例

```JSON
{
  "model": "deepseek-v4.1-flash-1017",
  "messages": [
    { "role": "system", "content": "You are a helpful assistant." },
    { "role": "user", "content": "Hello!" }
  ],
  "stream": false
}
```

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 模型名称，如 deepseek-v4.1-flash-1017 |
| `messages` | array | 是 | 消息数组，包含 role 和 content |
| `stream` | boolean | 否 | 是否流式输出，默认 false |
| `max_tokens` | integer | 否 | 最大生成 token 数 |
| `temperature` | float | 否 | 采样温度，0-2，默认 1 |
| `top_p` | float | 否 | 核采样，0-1 |
| `reasoning_effort` | string | 否 | 思考强度：high 或 max |
| `extra_body.thinking` | object | 否 | 启用思考模式：{ "type": "enabled" } |

## Node.js - 流式请求（SSE）

```JavaScript
// 流式请求 - 逐字实时返回（推荐用于打字机效果）
const axios = require('axios');

async function chatStream() {
  const response = await axios.post(
    'https://www.yhapiplatform.com/v1/chat/completions',
    {
      model: 'deepseek-v4.1-flash-1017',
      messages: [{ role: 'user', content: 'Hello!' }],
      stream: true
    },
    {
      headers: {
        'Authorization': 'Bearer sk-yhapi-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx',
        'Content-Type': 'application/json'
      },
      responseType: 'stream'
    }
  );

  response.data.on('data', (chunk) => {
    const lines = chunk.toString().split('\n');
    for (const line of lines) {
      if (!line.startsWith('data: ')) continue;
      const data = line.slice(6);
      if (data === '[DONE]') { console.log('\n[完成]'); return; }
      try {
        const json = JSON.parse(data);
        const content = json.choices?.[0]?.delta?.content;
        if (content) process.stdout.write(content);
      } catch (e) {}
    }
  });
}

chatStream().catch(console.error);
```

## Python - 非流式请求

```Python
import requests

API_KEY = 'sk-yhapi-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx'
BASE_URL = 'https://www.yhapiplatform.com/v1'

def chat(message):
    response = requests.post(
        f'{BASE_URL}/chat/completions',
        headers={
            'Authorization': f'Bearer {API_KEY}',
            'Content-Type': 'application/json'
        },
        json={
            'model': 'deepseek-v4.1-flash-1017',
            'messages': [
                {'role': 'system', 'content': 'You are a helpful assistant.'},
                {'role': 'user', 'content': message}
            ],
            'stream': False
        }
    )
    result = response.json()
    reply = result['choices'][0]['message']['content']
    tokens = result['usage']['total_tokens']
    return reply, tokens

reply, tokens = chat('Hello!')
print(f'回复: {reply}')
print(f'消耗 tokens: {tokens}')
```

## Python - 流式请求（SSE）

```Python
import requests
import json

API_KEY = 'sk-yhapi-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx'
BASE_URL = 'https://www.yhapiplatform.com/v1'

def chat_stream(message):
    response = requests.post(
        f'{BASE_URL}/chat/completions',
        headers={'Authorization': f'Bearer {API_KEY}', 'Content-Type': 'application/json'},
        json={'model': 'deepseek-v4.1-flash-1017', 'messages': [{'role': 'user', 'content': message}], 'stream': True},
        stream=True
    )
    for line in response.iter_lines(decode_unicode=True):
        if not line or not line.startswith('data: '): continue
        data = line[6:]
        if data == '[DONE]': break
        try:
            chunk = json.loads(data)
            content = chunk.get('choices', [{}])[0].get('delta', {}).get('content')
            if content: print(content, end='', flush=True)
        except json.JSONDecodeError: pass
    print()  # 最后换行

chat_stream('Hello!')
```

## 错误码

| HTTP 状态码 | 错误类型 | 说明 | 解决方法 |
| --- | --- | --- | --- |
| `200` | 成功 | 请求成功 | - |
| `201` | 创建成功 | 资源创建成功（如注册） | - |
| `400` | 参数错误 | 请求参数有误（缺少必填项、格式错误、超出范围） | 检查请求参数是否符合要求 |
| `401` | 未授权 | API Key 无效或已过期，用户名/密码错误 | 检查 API Key 或账号密码是否正确 |
| `402` | 余额不足 | 账户余额不足，无法完成本次请求 | 联系管理员充值 |
| `403` | 禁止访问 | 账号或 API Key 被禁用，无权执行该操作 | 联系管理员 |
| `404` | 资源不存在 | 请求的资源不存在（如用户、任务、记录） | 确认资源 ID 是否正确 |
| `409` | 资源冲突 | 用户名已被注册 | 更换用户名 |
| `416` | 限速触发 | 超出用户等级限速（并发/RPM/TPM/TPD），返回 416 | 查看限速说明，联系管理员提升等级 |
| `429` | 请求过多 | 超出上游 API 速率限制 | 降低请求频率，稍后重试 |
| `500` | 服务器错误 | 平台内部服务器错误 | 稍后重试 |
| `502` | 网关错误 | 无法连接到上游服务（DeepSeek/Claude/火山方舟） | 检查上游服务状态，稍后重试 |
| `504` | 超时 | 请求上游超时 | 稍后重试或减小 max_tokens |

## 思考模式（Thinking Mode）

启用思考模式后，模型会在回复前进行深度推理。适合复杂数学、编程、逻辑分析等场景。

### 启用方式

在请求体中添加以下两个参数（所有模型通用）：

```JSON
{
  "model": "deepseek-v4.1-flash-1017",
  "messages": [{"role": "user", "content": "Solve this math problem"}],
  "stream": false,
  "reasoning_effort": "high",
  "extra_body": {
    "thinking": {"type": "enabled"}
  }
}
```

> **本平台模型说明：** `claude-opus-4-8`、`claude-fable-5`、`gpt-5.5`、`gpt-5.6-sol` 支持上述思考模式参数，后端会自动适配。思考内容的显示取决于模型自身的支持情况。
>
>               **特殊说明：** `kimi-k3` **始终处于思考模式**，无法关闭，无需传递 thinking 参数。 `gpt-5.6-luna` 和 `gpt-5.6-terra` 为平衡/快速模型，思考模式支持取决于上游配置。

### 响应中的思考内容

启用思考模式后，响应的 `message` 对象（或流式响应的 `delta`）会额外包含 `reasoning_content` 字段：

```JSON
"message": {
  "role": "assistant",
  "reasoning_content": "Let me think step by step...",
  "content": "The answer is 42."
}
```

> 思考模式会增加 token 消耗，建议仅在需要深度推理时启用。

## Kimi 模型说明（K2.6 / K3）

`kimi-k2.6` 和 `kimi-k3` 由 Moonshot AI 提供。平台对 Kimi 系列做了参数兼容处理，使用时请注意以下特殊限制：

### 参数约束（kimi-k2.6 全线路 / kimi-k3 部分线路自动修正）

| 参数 | 约束 | 说明 |
| --- | --- | --- |
| `temperature` | 部分线路固定为 `1` | 该线路仅接受 1，其他值会报错；平台会按当前线路自动修正，用户无需处理 |
| `top_p` | 部分线路固定为 `0.95` | 平台自动修正 |
| `n` | 固定为 `1` | 不支持一次生成多条回复 |
| `presence_penalty` | 固定为 `0` | 不支持 |
| `frequency_penalty` | 固定为 `0` | 不支持 |
| `max_tokens` | 默认 `32768` | 未传时平台自动设置 |

> `kimi-k3` 已接入平台线路调度（单资源/多资源/直供线路），管理员可在后台切换线路；各线路计费口径一致。参数约束仅在需要修正的线路上自动生效，其余线路按用户传入值原样执行。

### Kimi K3 特殊说明

`kimi-k3` 是 Moonshot 迄今最强旗舰模型，具备以下特性：

- **2.8 万亿参数**，基于 KDA 混合线性注意力机制
- **100 万 token 上下文窗口**，适合超长文档处理
- **原生视觉理解**，支持图片和视频输入
- **不支持关闭思考模式**，始终处于 reasoning 状态

> ⚠️ Kimi K3 始终处于思考模式，无法关闭。调用 `/v1/chat/completions` 时无需（也不应）传递 `thinking` 或 `reasoning_effort` 参数，模型会自动返回 reasoning_content。调用 `/v1/responses` 时可通过 `reasoning.effort` 控制思考强度（详见 Responses 接口章节）。

### Responses API（仅 kimi-k3）

`kimi-k3` 的 `/v1/responses` 通道正在对接中，当前请使用 `/v1/chat/completions`（文本/视觉/工具调用/思考全功能）。开放后将在 [Responses 接口](#docs-responses) 章节同步更新。

### 多模态支持

Kimi K2.6 和 K3 均支持图片和视频理解。在 `messages` 中使用数组格式的 `content` 传入 `image_url` 或 `video_url` 类型即可。

### Token 计费

按实际返回的 `usage.total_tokens` 计费。流式响应中 usage 位于最后一个 chunk 的 `choices[0].usage` 中，平台已自动适配解析。

> **提示：** 上述约束仅针对 Kimi 模型，不影响其他模型的参数使用。


### 流式响应格式 (SSE)

当 `stream: true` 时，接口返回 SSE 流。每个事件以 `data:` 开头，事件类型包括：

| 事件类型 | 说明 |
| --- | --- |
| `response.created` | 响应开始 |
| `response.output_text.delta` | 文本增量 |
| `response.reasoning_text.delta` | 思考过程增量 |
| `response.completed` | 响应完成（含 usage） |

### Node.js - 流式调用示例

```JavaScript
const axios = require('axios');

const API_KEY = 'sk-yhapi-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx';
const BASE_URL = 'https://www.yhapiplatform.com';

async function responsesStream() {
  const response = await axios.post(
    `${BASE_URL}/v1/responses`,
    {
      model: 'gpt-5.5',
      input: [{ role: 'user', content: '你好，请介绍一下自己' }],
      stream: true
    },
    {
      headers: {
        'Authorization': `Bearer ${API_KEY}`,
        'Content-Type': 'application/json'
      },
      responseType: 'stream'
    }
  );

  response.data.on('data', (chunk) => {
    const lines = chunk.toString().split('\n');
    for (const line of lines) {
      if (line.startsWith('data:')) {
        const data = line.replace('data:', '').trim();
        if (data === '[DONE]') { console.log('完成'); return; }
        try {
          const event = JSON.parse(data);
          if (event.choices?.[0]?.delta?.content) {
            process.stdout.write(event.choices[0].delta.content);
          }
        } catch (e) {}
      }
    }
  });
}

responsesStream().catch(console.error);
```

> **与 Chat Completions 的区别：**
>
>                 使用 `input` 替代 `messages` 传递对话内容
>                 支持 `previous_response_id` 实现多轮对话上下文
>                 可用模型：gpt-5.5/5.6 系列、claude-opus-4-8/4-7/fable-5、glm-5.2、kimi-k3
>                 DeepSeek 系列与 kimi-k2.6 请使用 `/v1/chat/completions`

> ⚠️ **kimi-k3 Responses 通道对接中：**当前 kimi-k3 请使用 `/v1/chat/completions`（文本/视觉/工具调用/思考全功能）。Responses 接口对该模型开放后本文档将同步更新。

## ZenAiVes3.0-Omni 专属说明

`ZenAiVes3.0-Omni` 是上海鲸泽智模科技有限公司自主研发的 Omni 多模态大模型：最大上下文 **1,048,576 tokens**（1M），原生思考模式，支持**图片输入**与**视频输入**。调用方式与标准对话接口完全一致（`POST /v1/chat/completions`），模型名填 `ZenAiVes3.0-Omni` 即可。

### 思考模式

ZenAiVes3.0-Omni 默认开启思考，思考与正文**原生分离**，客户端按标准 OpenAI 格式解析即可：

- **非流式**：思考在 `message.reasoning_content`，正文在 `message.content`
- **流式模式**：思考增量走 `delta.reasoning_content`、正文走 `delta.content`，`finish_reason` 语义不变
- **关闭思考**（直接出答案、更快更省 token）：请求里传 `"extra_body": {"chat_template_kwargs": {"enable_thinking": false}}`，此时只有 `content` 有值
- 思考 token 计入 `completion_tokens` 计费（`usage.reasoning_tokens` 返回思考部分数量）；多轮对话命中前缀缓存时 `usage.prompt_tokens_details.cached_tokens` 返回命中数（自动省钱省时）

### 思考强度（reasoning_effort）

支持三档思考强度，通过 `reasoning_effort` 参数控制（平台自动转换，客户端直接用 OpenAI 风格取值即可）：

| reasoning_effort | 说明 | token 消耗 |
| --- | --- | --- |
| `"xhigh"` 或 `"high"` 或 `"max"`（默认） | 深度思考，最彻底的推理链 | 最高 |
| `"medium"` | 中等思考，速度与质量平衡 | 中等 |
| `"low"` | 轻量思考，快速出答案 | 最低 |

> 平台自动映射：OpenAI 风格的 `high` / `max` → 上游的 `xhigh`；`medium` / `low` 原值透传。不传此参数时默认 `xhigh`。OpenAI 风格的 `thinking` 对象（`extra_body` 里的）会被平台自动清理，不会导致报错。

### 采样参数默认值（重要）

请求**不传** `temperature` / `top_p` / `top_k` 时，使用模型 `generation_config.json` 的**官方思考模式默认值**：`temperature 1.0 / top_p 0.95 / top_k 20`。请求**显式传了则覆盖默认**（一切以请求为准）：

| 场景 | 建议传值 | 说明 |
| --- | --- | --- |
| 默认思考模式 | **不传**（用官方默认 1.0 / 0.95 / 20） | 官方思考模式推荐采样参数，效果最佳 |
| 打榜评测 | `temperature: 0.1` | 低温度确定性输出 |
| 关闭思考场景 | `temperature: 0.7` | 非思考模式官方推荐值 |

> `top_k` 为 ZenAiVes3.0-Omni 专属透传参数（OpenAI 标准参数之外），可直接顶层传或放 `extra_body` 中；其他模型不支持此参数。

### 图片理解（多模态）

content 使用数组结构，`image_url.url` 支持公网 https 直链或 Base64（`data:image/jpeg;base64,...`，推荐前端 FileReader 读取本地文件转换）；多图就放多个 image_url 块。

```JSON
{
  "model": "ZenAiVes3.0-Omni",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}},
      {"type": "text", "text": "这张图里有什么？"}
    ]
  }],
  "temperature": 0.3,
  "max_tokens": 1024
}
```

### 视频理解

与图片同理，`video_url.url` 传 `data:video/mp4;base64,...` 或公网直链。视频 token 消耗较大（约每秒 2 帧 × 每帧数百 token），建议控制在 1~2 分钟内，长视频建议先抽帧再发。

```JSON

  "model": "ZenAiVes3.0-Omni",
  "messages": [{
    "role": "user",
    "content": [
      {"type": "video_url", "video_url": {"url": "data:video/mp4;base64,AAAA..."}},
      {"type": "text", "text": "视频里发生了什么？"}
    ]
  }],
  "temperature": 0.3
}
```

### 推荐参数

| 场景 | temperature | max_tokens |
| --- | --- | --- |
| 默认思考模式（日常/长文/代码） | **不传**（官方默认 1.0，配 top_p 0.95 / top_k 20） | 2048 ~ 4096+ |
| 打榜评测 | 0.1（显式传） | 按榜要求 |
| 关闭思考场景 | 0.7（显式传） | 2048 |

### 完整示例（Python）

```Python

    base_url='https://www.yhapiplatform.com/v1',
    api_key='sk-yhapi-xxx'
```

> **两阶段各自独立计费**：草稿按 480p 档位计费，正片按 1080p 档位计费。生成失败不扣费。

## 素材库接口

素材库用于管理视频生成所需的图片、视频、音频素材。上传后的素材获得 `asset://` 引用地址（**真实素材ID直通，ID 全生命周期不变**），可直接用于视频生成的 content 参数。素材按**令牌隔离**：用哪个令牌的 API Key 创建，素材就归属该令牌，只能操作自己的素材。

> **遗留兼容：**历史版本产生的包装ID（`asset-yh-*`）仍可正常查询/删除/用于视频生成（平台自动只读翻译为真实ID）；查询单个素材时若传入包装ID，响应会额外附 `real_id` 字段（上游真实 asset-ID，便于对账）。新上传的素材一律直接返回真实ID，无此字段。

### 接口总览

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/v1/assets` | POST | 创建素材：单条（sync 同步 / async 异步）与批量（urls 数组） |
| `/v1/assets/async` | POST | 异步上传（新·推荐）：立即返回真实素材ID，状态 Pending |
| `/v1/assets/get` | POST | 查询单个素材（id 支持素材ID 或异步任务ID） |
| `/v1/assets/list` | POST | 查询素材列表（分页/按名称/按分组） |
| `/v1/assets/batch/get` | POST | 按批次查询素材（批量上传的整批进度） |
| `/v1/assets/update` | POST | 更新素材名称 |
| `/v1/assets/delete` | POST | 删除素材 |
| `/v1/assets/{id}/content` | GET | 素材内容稳定地址（浏览器/下载器直接访问，支持断点续传） |

| `/v1/assets/groups/delete` | POST | 删除分组（级联删除组内素材） |

### 1. 创建素材（单条）—— POST /v1/assets

**POST** `/v1/assets`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `url` | string | 是 | 素材文件的公网可访问 URL（服务端会下载） |
| `group_id` | int | 是 | 分组 ID（正整数，须为当前令牌的分组） |
| `asset_type` | string | 否 | Image（默认）/ Video / Audio |
| `name` | string | 否 | 素材名称（上限64字符） |
| `upload_mode` | string | 否 | sync（默认，阻塞至审核完成后返回）/ async（立即返回任务ID） |
| `callback_url` | string | 否 | 异步上传结果回调地址（见第4节） |
| `callback_secret` | string | 否 | 回调签名密钥（可选） |

sync 响应（审核通过，返回真实素材ID）：

```JSON
{ "code": "success", "data": { "id": "asset-20260427120130-ngtck", "asset_url": "asset://asset-20260427120130-ngtck" } }
```

async 响应（立即返回，id 即任务ID，可直接用于 /v1/assets/get 轮询）：

```JSON
{ "code": "success", "data": { "id": "task-20260630120000-abcde", "status": "Processing" } }
```

### 2. 异步上传（新·推荐）—— POST /v1/assets/async

**POST** `/v1/assets/async`

直接分配**真实素材ID**（无需等任务回填），状态初始 `Pending`，通常 5~30 秒进入终态。请求体：`{ "url", "group_id", "asset_type"?, "name"? }`

```JSON
{ "code": "success", "data": { "id": "asset-20260716171312-pvq2l", "group_id": 8, "status": "Pending" } }
```

用返回的 id 调 `POST /v1/assets/get` 轮询：`Pending`（处理中）→ `Active`（可用）/ `Failed`（失败，带 error）。建议轮询间隔 ≥ 500ms。

### 3. 批量上传（仅异步）—— POST /v1/assets

传 `urls` 数组（最多 50 条，非空时忽略单条 url）。批次内共用 asset_type 与 name：

```JSON
{
  "group_id": 8, "asset_type": "Image", "name": "batch-test",
  "urls": ["https://example.com/1.jpg", "https://example.com/2.jpg"]
}
```

响应含 `batch_id`（用于 `POST /v1/assets/batch/get` 轮询整批进度）：

```JSON
{
  "code": "success",
  "data": {
    "batch_id": "task-20260713070255-c9a9f950", "task_id": "task-20260713070255-c9a9f950",
    "total": 3, "status": "Processing",
    "items": [{ "source_url": "https://example.com/1.jpg", "status": "Processing" }]
  }
}
```

> URL 扩展名要求——图片：jpeg/jpg/png/webp/bmp/tiff/gif/heic；视频：mp4/mov；音频：wav/mp3。图片高度 300~6000px。素材要求见下方表格。

### 4. 上传结果回调（Webhook）

单条 async 与批量上传可携带 `callback_url`。平台以**自有域名中继回调**（你只会收到来自本平台的回调请求）：

- 触发时机：单条任务完成/失败时一次；整批完成时一次（载荷覆盖批内全部素材）
- 请求头：`Content-Type: application/json`、`X-Track-Id`（任务ID，幂等键）；填了 callback_secret 时附 `X-Webhook-Signature` = HMAC-SHA256(secret, 原始请求体字节) 十六进制
- 载荷与任务查询结果同构：`{ "code": 200, "task_id", "status": "completed|failed", "total_count", "done_count", "result": { "items": [...] } }`，`items[].asset_url` 为 asset:// 引用地址
- 收到回调请尽快返回 2xx；平台投递失败会有限次退避重试（立即 +1s +3s），仍失败可用查询接口兜底
- 验签必须用原始请求体字节计算，不要解析后重新序列化

## 真人素材（H5 人脸认证）

真人素材用于生成"数字人 / 真人形象"类视频。与普通素材不同，真人素材上传前必须先完成 H5 人脸认证授权：授权方在 H5 页面刷脸成功后，系统创建一个真人素材组（艺人组），后续上传到该组的素材会做人脸一致性校验——只有与授权刷脸同一个人的素材才能通过审核（否则返回 FaceMismatch）。审核通过后获得 `asset://` 引用地址，可直接用于视频生成。

### 整体流程

1. 获取 H5 认证链接：`POST /v1/assets/real-person/auth/link`（提交艺人名称）
2. 授权方刷脸：打开返回的 h5_url，在 120 秒内完成人脸认证
3. 查询艺人组：`GET /v1/assets/real-person/groups`（拿到真人组 group_id，即返回项的 id）
4. 上传真人素材：`POST /v1/assets`（或 `/v1/assets/async`），传真人组 id，触发人脸校验
5. 用于视频生成：`asset://` 引用地址传入 `POST /v1/video/generations`

> H5 认证链接有效期 120 秒且使用一次后失效，超时需重新获取。真人素材组按令牌隔离：用哪个令牌的 API Key 发起认证，组就归属该令牌。每次授权都会创建独立真人组。旧路径 `/v1/real-person/*` 保留兼容，与新路径等价。

### 1. 获取真人认证 H5 链接

**POST** `/v1/assets/real-person/auth/link`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `artist_name` | string | 是 | 艺人（授权组）名称，最多32字符，不可重复 |
| `artist_desc` | string | 否 | 艺人描述，最多300字符 |

```JSON
{
  "code": "success",
  "data": {
    "h5_url": "https://...",
    "tip": "请让授权方在 120 秒内打开并完成认证，链接使用后失效"
  }
}
```

请将 h5_url 转交授权方（真人本人）在手机上打开完成刷脸。认证成功后系统自动为当前令牌创建真人素材组。

### 2. 查询真人素材组

**GET** `/v1/assets/real-person/groups`

```JSON
{
  "code": "success",
  "data": {
    "items": [{
      "id": 128,
      "group_id": "group-xxx",
      "artist_name": "张三",
      "artist_desc": "品牌代言人真人素材组",
      "authorized_at": "2026-04-27T12:00:29+08:00",
      "asset_count": 3
    }]
  }
}
```

> 上传真人素材时使用 `id`（平台组 ID，整数）。刚完成刷脸列表为空时，等 1~2 秒重试；始终为空说明刷脸未成功或链接超时，请重新获取认证链接。

### 3. 上传真人素材（复用素材库接口）

通过 `POST /v1/assets`（或 `/v1/assets/async`）上传，`group_id` 指定为真人组 `id` 即触发人脸一致性校验：

```JSON
{
  "url": "https://example.com/zhangsan-face.jpg",
  "asset_type": "Image",
  "name": "张三-正脸",
  "group_id": 128
}
```

> 上传素材必须与授权刷脸为同一个人，否则返回 `{"error":{"message":"FaceMismatch: 上传素材与授权认证人脸不一致"}}`。同一真人组只应上传同一位真人的素材。素材要求与普通素材一致（图片高度300~6000px、URL公网可访问）。

### 4. 删除真人素材 / 真人组

| 接口 | 请求体 | 说明 |
| --- | --- | --- |
| `POST /v1/assets/real-person/assets/delete` | `{"id": "asset-xxx"}` | 删单个真人素材（不含 asset:// 前缀），永久移除不可恢复 |
| `POST /v1/assets/real-person/groups/delete` | `{"id": 128}` | 删整组（连同组内全部素材一并永久移除，不可恢复） |

## 素材管理（/v1/material）

素材管理是一个**独立的本地素材库**模块：分组管理 + 素材上传（在线 URL 或 base64 图片）+ 分页查询。素材文件存储在**本平台自有文件服务**（返回的 url 为本平台长期有效地址，带随机访问令牌）。可选 `auto_asset` 同步注册到素材库，获得 `asset://` 引用后即可直接用于视频生成。

### 接口说明

| --- | --- | --- |

> file_type 取值 image / video / audio。支持类型——图片：jpeg/jpg/png/webp/bmp/tiff/gif/heic；视频：mp4/mov；音频：wav/mp3。单文件上限 50MB。url 为本平台长期有效地址（带随机访问令牌，可直链给浏览器/下载器，也满足素材库注册的公网可访问要求）。

1. 新建分组：`POST /v1/material/groups` → 取 `data.id`

## 专业版视频生成接口（Professional Edition · 官方格式）

> ⚠️ ⚠️ 本节模型为独立授权能力：**需要联系管理员进行授权后才能够使用**，未授权调用将返回 403。授权后按下方文档正常调用。

专业版系列采用**火山方舟官方格式**的独立端点：请求传参（`content[]` 数组）与响应结构与官方完全一致，仅域名不同，可直接复用官方 SDK 与示例代码。平台扩展参数 `bitrate_mode`（码率模式）在同端点透传。素材引用与普通版**统一**：content 中各模态 url 支持 `asset://`（统一素材库，推荐）、`media://`（真人素材库，兼容旧引用）与公网 URL / Base64。

### 任务类型（按 content 自动判定）

| 任务类型 | 所需输入 | 说明 |
| --- | --- | --- |
| 文生视频 | 仅提示词 | content 只有 text |
| 图生视频（首帧） | 1 张图片 | role=first_frame 或不带 role |

| 多模态参考生视频 | 图/视频/音频组合 | 参考图带 role=reference_image，或混合音视频素材 |

> 素材引用三种形式（与普通版统一）：`asset://<素材ID>` 统一素材库（推荐，**首次引用自动同步到专业版素材通道，无需重复注册**）；`media://<media_id>` 真人素材库（兼容旧引用）；公网 URL / Base64 直接透传。含真人人物（人脸出镜）的素材可能被版权检测拒绝，请优先使用统一素材库的 asset:// 引用或在真人素材库注册后引用。

### 查询任务 - 响应字段（官方格式）

| 字段 | 说明 |
| --- | --- |
| `id` | 任务 ID（ag_ 前缀） |
| `model` | 模型名称 |
| `status` | queued / running / succeeded / failed / cancelled |
| `content.video_url` | 第一个产物的视频地址（计费完成后才返回） |
| `content.video_urls` | 平台扩展：全部产物地址数组（n>1 时返回） |
| `content.last_frame_url` | 尾帧图片地址（return_last_frame=true 时返回） |
| `created_at` | 任务创建时间（Unix 时间戳，秒） |
| `duration` / `ratio` / `resolution` / `generate_audio` / `output_format` | 任务实际参数回显 |
| `bitrate_mode` | 码率模式回显（平台扩展，high / standard） |
| `usage` | 用量对象：`completion_tokens` = 本任务实际消耗计量（计费依据），`total_tokens` 同值 |
| `error` | `{code, message}` 失败信息（status=failed 时返回，否则为 null） |

> 结算期间查询返回 `status:"running"`（稍后再查即得终态）；余额不足时返回 HTTP 402 与错误对象，充值后重新查询即可获取视频。

### 取消与删除任务

`DELETE /api/v3/contents/generations/tasks/:id` 按任务当前状态区分：

| 当前状态 | 是否支持 | 结果 |
| --- | --- | --- |
| `queued` | 是 | 取消排队，任务状态变为 `cancelled`（不结算；上游资源已占用，取消请谨慎） |
| `running` | 否（409） | 不支持强制中止，保留任务继续查询 |
| `succeeded`（已结算） | 是 | 删除任务记录，删除后不能再查询 |
| `failed` / `cancelled` | 是 / 否（409） | 失败任务可删除记录；已取消任务不重复操作 |

> 删除前请先归档任务状态、用量与视频地址；`succeeded` 未结算的任务会返回 409（先查询完成结算再删除）。客户端超时不等于任务失败——请继续用原任务 ID 查询，不要立即重复创建，以免重复计费。

### 任务状态回调（callback_url）

创建任务携带 `callback_url`（HTTPS）时，任务到达终态且可交付后平台向该地址 POST 官方结构任务对象（与查询响应同构，含 `content.video_url`、`content.last_frame_url`、`usage`、`error`），请求头附 `X-Track-Id`（任务 ID，幂等键）。

- 接收方应使用公网 HTTPS、快速返回 2xx，耗时逻辑放异步队列
- 按任务 `id` 幂等去重；收到回调后再调查询接口获取最终权威状态
- 平台投递失败按 5s/15s/60s/5m/15m 退避重试至多 5 次；请保留超时补偿轮询，不要只依赖回调

```Shell
# 创建任务携带回调（回调体 = 查询响应同构，POST 到你的 HTTPS 地址）
curl -X POST "https://www.yhapiplatform.com/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer sk-xxx" -H "Content-Type: application/json" \
  -d '{"model":"doubao-seedance-2-0-Professional Edition","content":[{"type":"text","text":"一只猫在窗台"}],"duration":5,"callback_url":"https://your-server.com/video-task-callback"}'

# 取消排队中的任务（queued → cancelled；运行中不可中止）
curl -X DELETE "https://www.yhapiplatform.com/api/v3/contents/generations/tasks/ag_xxxxxxxx" \
  -H "Authorization: Bearer sk-xxx"
```

### 计费说明

任务完成后按实际消耗计量（`usage.completion_tokens` 口径）计费，单价见「定价」页对应模型条目，支持峰谷定价与用户单独定价；创建任务要求账户余额不低于视频生成门槛。用量以查询接口返回的 usage 为准，可在「使用统计」中核对。

### Node.js 示例（官方格式）

```JavaScript
const axios = require('axios');

const API_KEY = 'sk-yhapi-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx';
const BASE_URL = 'https://www.yhapiplatform.com';
const headers = { 'Authorization': `Bearer ${API_KEY}`, 'Content-Type': 'application/json' };

// 创建专业版视频任务（官方 content[] 格式；素材统一用 asset://，bitrate_mode 为平台扩展参数）
async function main() {
  const resp = await axios.post(`${BASE_URL}/api/v3/contents/generations/tasks`, {
    model: 'doubao-seedance-2-0-Professional Edition',
    content: [
      { type: 'text', text: '图片1中的人物对着镜头微笑挥手，背景是夕阳下的海边' },
      { type: 'image_url', image_url: { url: 'asset://你的素材ID' }, role: 'reference_image' }
    ],

    duration: 5,
    resolution: '1080p',
    generate_audio: true,
    bitrate_mode: 'high',
    callback_url: 'https://your-server.com/video-task-callback'
  }, { headers });
  const taskId = resp.data.id;
  console.log('Task ID:', taskId);

  // 每 5 秒轮询一次（官方扁平响应）

    const r = await axios.get(`${BASE_URL}/api/v3/contents/generations/tasks/${taskId}`, { headers });
    const d = r.data;
    console.log('Status:', d.status);
    if (d.status === 'succeeded') {
      clearInterval(timer);
      console.log('视频地址:', d.content.video_url);
      console.log('实际消耗计量:', d.usage.completion_tokens);
    } else if (d.status === 'failed') {

    }
  }, 5000);

main().catch(console.error);
```

## 真人素材库（专业版）

> ⚠️ ⚠️ 真人素材库为独立授权能力：**需要联系管理员进行授权后才能够使用**。专业版视频模型引用真人素材（人物出镜的图片/视频/音频）时，必须先在本库注册后以 `asset://` 或 `media://` 引用，直接传公网 URL 会被版权检测拒绝。

### 官方格式接口（推荐，与火山方舟 Assets API 出入参完全一致）

本库提供与官方私域素材库（Assets API）**请求/响应字段完全一致**的接口：全部 **POST**、帕斯卡命名、嵌套 Filter 结构，可直接复用官方示例代码的字段与流程（仅鉴权用平台 API Key，域名不同）。素材 ID 为官方风格 `asset-` 前缀，可直接以 `asset://<Id>` 在专业版视频生成（`POST /api/v3/contents/generations/tasks`）的 content 中引用。

| 接口 | 方法 | 官方 Action | 入参 → 出参 |
| --- | --- | --- | --- |
| `/api/v3/assets` | POST | CreateAsset | `{GroupId?, URL, AssetType(Image/Video/Audio), Name?}` → `{"Id": "asset-..."}`（异步检测，轮询 GetAsset 等 Active；GroupId 不传自动用默认组） |
| `/api/v3/assets/get` | POST | GetAsset | `{Id}` → `{Id, GroupId, Name, AssetType, Status, URL, CreateTime, UpdateTime, Moderation:{Strategy}, ProjectName}`；Status：Active / Processing / Failed（实时刷新） |
| `/api/v3/assets/list` | POST | ListAssets | `{Filter:{GroupIds?, Statuses?, Name?, GroupType?}, MaxResults?, SortBy?(CreateTime/UpdateTime), SortOrder?(Asc/Desc), NextToken?}` → `{Items:[...], NextToken}`（Items 元素与 GetAsset 同构，URL 为 null 时需单独调 GetAsset 取地址） |
| `/api/v3/assets/update` | POST | UpdateAsset | `{Id, Name}` → `{}` |
| `/api/v3/assets/delete` | POST | DeleteAsset | `{Id}` → `{}` |
| `/api/v3/asset-groups/list` | POST | ListAssetGroups | `{Filter:{Name?, GroupIds?}, MaxResults?, NextToken?}` → `{Items:[{Id, Name, Description, GroupType:"LivenessFace", ProjectName, CreateTime, UpdateTime}], NextToken}`（首次调用自动开通默认组） |
| `/api/v3/asset-groups/get` | POST | GetAssetGroup | `{Id}` → 单个组对象（字段同上） |
| `/api/v3/asset-groups/update` | POST | UpdateAssetGroup | `{Id, Name?, Description?}` → `{}` |
| `/api/v3/asset-groups/delete` | POST | DeleteAssetGroup | `{Id}` → `{}`（仅空组可删） |

> 与官方的差异共四点（代码内已兼容）：① 鉴权为平台 API Key（`Authorization: Bearer`），非官方 AK/SK——字段结构对齐即可复用官方示例代码；② `LastInferenceTime` 未接入本地统计，按官方「无调用记录不返回」口径省略；③ 官方有、本地无对应能力的参数（`ProjectName`、`Filter.GroupType`、`SortBy` 其他取值）静默忽略；④ **组的创建方式不同**——官方需先走真人认证（`CreateVisualValidateSession` H5 人脸认证 → `GetVisualValidateResult` 获取 GroupId，每组绑定一个真人，素材入库做人脸一致性比对）后才能 CreateAsset；**本平台无需真人认证**，首次调用 `asset-groups/list` 自动开通默认组，`CreateAsset` 不传 GroupId 即入默认组（按官方流程传 GroupId 也完全兼容），官方 Step 1 的两个认证接口本平台不提供。同一路由的 REST 风格别名（GET/PUT/DELETE）继续可用；视频生成里 `asset://<Id>` 的解析顺序：先查统一素材库、再查本库。

```Python
import requests, time

BASE_URL = "https://www.yhapiplatform.com"
API_KEY = "sk-yhapi-xxx"
headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}

# 1. 创建素材（官方字段）
resp = requests.post(f"{BASE_URL}/api/v3/assets", headers=headers, json={
    "URL": "https://example.com/person.jpg",
    "AssetType": "Image",
    "Name": "正脸照片"
})
asset_id = resp.json()["Id"]  # asset-xxxxx
print("素材:", asset_id)

# 2. 轮询至 Active
for _ in range(30):
    d = requests.post(f"{BASE_URL}/api/v3/assets/get", headers=headers, json={"Id": asset_id}).json()
    print("状态:", d["Status"])
    if d["Status"] == "Active":
        break
    if d["Status"] == "Failed":
        raise SystemExit("素材检测失败")
    time.sleep(3)

# 3. 专业版视频生成（官方格式，asset:// 引用）
resp = requests.post(f"{BASE_URL}/api/v3/contents/generations/tasks", headers=headers, json={
    "model": "doubao-seedance-2-0-Professional Edition",
    "content": [
        {"type": "text", "text": "人物微笑着向镜头挥手"},
        {"type": "image_url", "image_url": {"url": f"asset://{asset_id}"}, "role": "reference_image"}
    ],
    "duration": 5
})
print("视频任务:", resp.json()["id"])
```

```JSON
    "status": "Processing"
  }
}
```

### 2. 查询素材

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `media_id` | string | 是 | 素材 ID（media:// 前缀亦可） |
| `auth_timeout` | integer | 否 | 返回的文件/封面地址有效期（秒） |

关键字段：`status`（Processing → Normal 表示就绪）、`third_party_status`（版权检测：Init/Processing → Success 可用于生成，Failed 不可用并附原因）、`cover_url`（封面图）、`files`（文件地址/时长/宽高）。

> 建议轮询本接口直到 `status=Normal` 且 `third_party_status=Success` 后再用于视频生成；同一素材只需注册一次，media_id 长期有效。

### 3. 搜索我的素材

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `keyword` | string | 否 | 标题关键字（中英文/数字/空格/连字符/下划线） |
| `media_type` | string | 否 | image / video / audio |
| `page_no` | integer | 否 | 页码，默认 1 |
| `page_size` | integer | 否 | 每页条数，默认 10，最大 50 |

### 4. 更新素材

入参：`media_id`（必填）+ `title` / `description` / `media_tags` / `cover_url`（至少一项，cover_url 仅视频素材有效）。

### 5. 删除素材

入参：`media_ids`（数组或逗号分隔字符串）。仅能删除本人素材；响应返回 `deleted`（已删除）、`ignored`（不存在/无权限）。

> ⚠️ ⚠️ 素材删除后，引用该素材的历史任务不受影响，但新建任务将无法再引用。

### 文件限制

| 类型 | 格式 | 限制 |
| --- | --- | --- |
| 图片 | jpeg / jpg / png / webp | 小于 20MB；短边不低于 400px，长边不超过 8000px |
| 视频 | mp4 / mov | 不超过 100MB；宽高（px）范围 [300, 4096]，像素（宽×高）范围 [409600, 927408] |
| 音频 | mp3 / wav | 不超过 15MB |

### 完整流程示例（Python）

```Python
import requests, time

BASE_URL = "https://www.yhapiplatform.com"
API_KEY = "sk-yhapi-xxx"
headers = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}

# 1. 注册真人素材
resp = requests.post(f"{BASE_URL}/v1/pro-assets", headers=headers, json={
    "url": "https://example.com/person.jpg",
    "media_type": "image",
    "title": "正脸照片"
})
media_ref = resp.json()["data"]["media_ref"]  # media://xxxxx
print("素材:", media_ref)

# 2. 轮询素材直到可用
for _ in range(30):
    resp = requests.post(f"{BASE_URL}/v1/pro-assets/get", headers=headers,
                         json={"media_id": media_ref})
    d = resp.json()["data"]
    if d["status"] == "Normal" and d["third_party_status"] == "Success":
        break
    if d["third_party_status"] == "Failed":
        raise SystemExit("素材检测失败:" + str(d.get("third_party_error")))
    time.sleep(3)

# 3. 创建专业版视频任务（官方格式端点，POST /api/v3/contents/generations/tasks）
resp = requests.post(f"{BASE_URL}/api/v3/contents/generations/tasks", headers=headers, json={
    "model": "doubao-seedance-2-0-Professional Edition",
    "content": [
        {"type": "text", "text": "人物微笑着向镜头挥手"},
        {"type": "image_url", "image_url": {"url": media_ref}, "role": "reference_image"}
    ],
    "duration": 5,
    "resolution": "1080p",
    "bitrate_mode": "high"
})
task_id = resp.json()["id"]
print("视频任务:", task_id)

# 4. 轮询任务（官方扁平响应）
while True:
    r = requests.get(f"{BASE_URL}/api/v3/contents/generations/tasks/{task_id}", headers=headers)
    d = r.json()
    print("状态:", d["status"])
    if d["status"] == "succeeded":
        print("视频地址:", d["content"]["video_url"])
        break
    if d["status"] == "failed":
        raise SystemExit("生成失败:" + str(d.get("error")))
    time.sleep(5)
```

## Seedance Gateway（素材/人像 OpenAPI 网关）

素材组、素材与真人人像认证的统一网关，采用**火山 OpenAPI Action 风格**。视频接口与素材接口使用**同一枚 API Key**（`Authorization: Bearer sk-xxx`）。素材引用 `asset://<asset_id>` 可直接用于专业版与普通版视频生成。

### 接口地址

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/seedance/proxy/openapi?Action=<ACTION>&Version=2024-01-01` | POST | 素材组/素材 10 个 Action（见下表） |
| `/api/seedance/face-verifications` | POST | 创建真人认证会话（返回 h5_url） |
| `/api/seedance/face-verifications/{verification_id}` | GET | 查询认证状态（verified 后返回 group_id） |
| `/api/seedance/healthz` | GET | 健康检查（无需 Token） |

### 支持的 Action

| Action | 请求体要点 | 说明 |
| --- | --- | --- |
| `CreateAssetGroup` | `{"Name"(≤64),"Description"?,"GroupType":"AIGC"}` | 创建 AIGC 素材组；返回 `Result.Id` |
| `ListAssetGroups` | `{"Filter":{"GroupType":"AIGC\|LivenessFace","GroupIds"?,"Name"?},"PageNumber","PageSize"≤100}` | 分页查询素材组（含 item 计数口径的 TotalCount） |
| `GetAssetGroup` | `{"Id"}` | 素材组详情 |
| `UpdateAssetGroup` | `{"Id","Name"?}` | 改名（Name/Description 至少一项；描述当前仅记录不改上游） |
| `DeleteAssetGroup` | `{"Id"}` | 删除组及组内素材，不可恢复 |
| `CreateAsset` | `{"GroupId","URL","AssetType":"Image\|Video\|Audio","Name"?}` | 异步创建素材，返回 `Result.Id`；须轮询 GetAsset 至 Active |
| `ListAssets` | `{"Filter":{"GroupIds"?,"GroupType"?,"Statuses"?,"Name"?},"PageNumber","PageSize"≤100}` | 分页查询素材（仅当前账号） |
| `GetAsset` | `{"Id"}` | 素材详情与状态（Active/Processing/Failed；Failed 带 `Error`） |
| `UpdateAsset` | `{"Id","Name"}` | 修改素材名称 |
| `DeleteAsset` | `{"Id"}` | 删除素材，不可恢复 |

> 响应统一 `{"ResponseMetadata":{"RequestId","Action","Version","Error"?},"Result":{...}}`，请保存 RequestId 用于排障。错误时 HTTP 状态保留业务码、`ResponseMetadata.Error` 携带 `{Code, Message}`。OpenAPI 入口必须 POST（GET 返回 405）；不在白名单的路径返回 404 `unsupported_seedance_route`。`Result.URL` 为平台长期有效地址；视频生成引用请使用稳定标识 `asset://<asset_id>`。

### 真人认证（face-verifications）

```JSON
POST /api/seedance/face-verifications        // body 可为 {} 或 {"return_url":"https://..."}
→ { "verification_id": "fv_xxxxxxxxx", "status": "waiting_user",
    "h5_url": "https://...", "expires_at": "2026-09-28T12:00:00.000Z" }

GET /api/seedance/face-verifications/fv_xxxxxxxxx
→ { "verification_id": "fv_xxxxxxxxx", "status": "waiting_user" | "verified" | "expired",
    "group_id": "128" }   // verified 时返回
```

让终端用户在有效期内打开 `h5_url` 完成活体认证；业务系统保存 `verification_id` 轮询，`verified` 后拿 `group_id`（LivenessFace 组），再用 `CreateAsset` 向该组上传**与认证本人一致**的素材（触发人脸一致性校验，不一致返回 FaceMismatch 错误）。

> ⚠️ ⚠️ H5 认证链接**120 秒有效且用后即失效**（上游限制）：请让用户拿到 h5_url 后立即完成刷脸；过期（expired）后重新创建会话即可。认证通过不代表后续任意素材自动通过审核。

```Shell
# 创建素材组
curl -X POST "https://www.yhapiplatform.com/api/seedance/proxy/openapi?Action=CreateAssetGroup&Version=2024-01-01" \
  -H "Authorization: Bearer sk-xxx" -H "Content-Type: application/json" \
  -d '{"Name":"品牌素材组","GroupType":"AIGC"}'

# 创建素材（异步；轮询 GetAsset 至 Active 后用 asset:// 引用）
curl -X POST "https://www.yhapiplatform.com/api/seedance/proxy/openapi?Action=CreateAsset&Version=2024-01-01" \
  -H "Authorization: Bearer sk-xxx" -H "Content-Type: application/json" \
  -d '{"GroupId":"3339","URL":"https://example.com/ref.jpg","AssetType":"Image","Name":"人物参考图"}'
```

### 视频生成 API 集成说明

Seedance 视频生成是独立的 REST API，不通过 OpenAI SDK 调用。需要自行编写 HTTP 请求代码集成。

| 配置项 | 值 |
| --- | --- |
| Base URL | `https://www.yhapiplatform.com` |
| 认证方式 | Bearer Token（JWT Token，登录后获取） |
| 创建任务 | `POST /api/video/create` |
| 查询状态 | `GET /api/video/status/{taskId}` |
| 模型（Seedance 2.0） | `doubao-seedance-2-0-260128` |
| 模型（Seedance 2.0 Fast） | `doubao-seedance-2-0-fast-260128` |
| 模型（Seedance 2.5） | `doubao-seedance-2.5`（时长上限 30 秒） |
| 模型（专业版系列） | `doubao-seedance-2-0-Professional Edition` / `doubao-seedance-2-0-fast-Professional Edition` / `doubao-seedance-2.5-Professional Edition`（需授权；走官方格式端点 `POST /api/v3/contents/generations/tasks`，见「专业版视频生成接口」章节） |

1. 从本平台 "API Keys" 页面复制你的 API Key（格式：sk-yhapi-xxxxxxxx）
2. 打开 Postman，新建一个 Collection
3. 创建视频任务：                                    Method: **POST**                   URL: `https://www.yhapiplatform.com/api/video/create`                   Headers: `Authorization: Bearer {你的JWT Token}`                   Body (raw JSON):                     {   "prompt": "A serene Japanese garden with cherry blossoms",   "model": "doubao-seedance-2-0-260128",   "ratio": "16:9",   "duration": 5,   "resolution": "720p" }
4. 查询任务状态：                                    Method: **GET**                   URL: `https://www.yhapiplatform.com/api/video/status/{taskId}`                   Headers: `Authorization: Bearer {你的JWT Token}`

视频生成是异步流程，标准集成步骤：

1. **用户登录**：调用 `/api/auth/login` 获取 JWT Token
2. **创建任务**：POST `/api/video/create` 提交生成请求
3. **轮询状态**：每隔 5 秒 GET `/api/video/status/{taskId}` 查询进度
4. **获取结果**：当 status 变为 `succeeded` 时，从 videoUrl 下载视频

详细的请求参数和代码示例请参考上方"视频生成接口"章节。

> 视频生成 API 使用 API Key 认证（与对话 API 相同），支持在任何 HTTP 客户端中直接调用。

> 如遇兼容性问题，请确保软件支持 OpenAI API 的 `/v1/chat/completions` 端点。部分旧版本软件可能不支持，建议升级到最新版本。
