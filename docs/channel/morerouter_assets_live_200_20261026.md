# MoreRouter 素材接口与 200 并发实网测试（2026-10-26）

本次未发现本地长时间持锁、连接池等待超时或本地 503。200 并发创建中 124 次成功、76 次被上游限流；失败请求均已到达 MoreRouter，其 HTTP 502 响应中包含火山的 HTTP 429 / `QuotaWriteQPMExceeded`。不能将本轮结果表述为“200 次创建全部成功”。

## 环境与范围

- 当前工作区网关代码，经过真实 HTTP 路由、Token 鉴权、用户归属和 `ark-compatible` 适配，调用 `https://morerouter.cn/api`，命名空间 `asset_manager`。
- 覆盖素材及素材组共 10 个 Create/Get/List/Update/Delete 接口，同时使用 REST 与 Action 两种网关入口。
- 真实 MySQL 5.7.43-log，随机隔离主库及日志库，连接池分别为 30、5；开启 GORM 预编译语句，关闭 Redis 和鉴权内存缓存。
- 每轮使用一个独立测试容器，CPU 上限 2 核、内存上限 1 GiB；各容器 `OOMKilled=false`。未部署或修改线上配置。
- 素材使用 OpenCV 公共水果参考图，不包含真人；未调用视频生成或真人认证。
- 创建请求不重试。删除遭限流时低并发退避重试；清理只处理本次 ID 日志及本次专用组内带唯一名称前缀的素材。

## 实际接口契约

- 图片的 `AssetType` 应为 `Image`。文档示例的 `image` 实测被拒绝，内层错误为 `InvalidParameter.AssetType`。
- `ListAssets`、`ListAssetGroups` 必须带 `Filter.GroupType: "AIGC"`。分页采用 `PageNumber` / `PageSize`，已实际跨页验证。
- MoreRouter 成功响应直接返回对象字段。当前网关可处理，Action 入口会包装成 `ResponseMetadata` / `Result`。
- MoreRouter 将上游 429 和 404 包装成 HTTP 502，需解析内层错误。这一行为在网关出站 HTTP 观测和直接请求中均可见。
- 国际命名空间及 MoreRouter 的游标分页未实测。

素材组创建、修改、删除，素材修改及基础创建均成功。76 次创建失败全部为 `QuotaWriteQPMExceeded`；列表、分组查询及首次删除的失败为 `AccountFlowLimitExceeded`。13 个删除失败请求经直接上游退避重试全部成功。

出站观测确认 MoreRouter 本身返回这些 502。素材列表请求可能触发多个上游分页请求，本轮 200 个网关列表请求实际发出 249 个上游请求，因此上游请求数高于客户端请求数。

第一轮主池峰值为 30/30，各详情查询轮末及测试末均为 0；没有记录满池持续时间。累计借连接等待 14116 次、136168.25 ms，平均约 9.65 ms。该累计值是并发 SQL 等待时间之和，不是连续占满时长。每 100 ms 采样的 InnoDB 锁等待事务峰值为 0，监测错误为 0。

原测试假设 200 次提交全部成功，因此成功的 12 次列表还触发了“预期 201、实际 125”的断言；实际列表总数是正确的。夹具已改为按观测到的创建数核对，没有为重跑断言再创建一批资源。原实网运行保留失败状态及原始记录。

## 人为持锁回归

在隔离 MySQL 库额外运行 7 个既有回归测试，全部通过：

- 人为保持素材身份行锁后，受阻注册约 3.005 秒返回超时；连接池恢复到仅有测试故意保持的那条事务连接，数据库不再留有锁等待事务。
- 有短请求期限时，受阻删除及新增别名能按期限退出并释放连接。
- 已有素材轮询可绕过人为保持的分组锁。
- 同组的另一素材写入可以继续；等待删除不会永久阻塞后续操作。
- 删除队列等待不会提前占用数据库连接。
- 列表借连接等待和删除队列等待均受期限约束。
- 素材事务结束后恢复连接原有的 MySQL 锁等待配置。

代码中素材本地操作上限 15 秒，单次写事务上限 3 秒，素材事务使用的 MySQL 行锁等待设置为 2 秒。MySQL 5.7 的周期性超时检查可能让 3 秒 Go 上下文先返回，本次即观察到这一情况；回归同时验证了服务器等待者最终清空。
