## 方法

1. 经真实网关创建专用分组，并查询验证归属与上游连接。
2. 使用 300 个线程在屏障处同时释放，调用 `POST /?Action=CreateAsset&Version=2024-01-01`，观测到客户端在途请求峰值为 300。网关适配到供应商 `/v1/assets/async`。
3. 每个请求指定同一个已拥有的 `GroupId`、`AssetType: Image` 和不同名称；交替使用 OpenCV 公开 `fruits.jpg` / `baboon.jpg`，各 150 次。本轮是 300 次素材注册，不是 300 张不同源图片。实际获得的 300 个素材 ID 均不同。
4. 通过官方 `GetAsset` Action 查询全部 ID；轮询最多 60 个请求同时在途，同一个 ID 的两次查询间隔至少 3 秒。已成功的 ID 不再重复轮询。本次没有创建重试或查询错误重试。
5. 每秒请求网关 `/api/ready`，同时按约 0.5 秒间隔加采样耗时检查该隔离库连接及 InnoDB 锁等待。核对最终素材登记、用户/组归属、任务数与用量。
