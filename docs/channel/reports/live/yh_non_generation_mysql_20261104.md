# YH 编译服务非生成接口实测

2026-11-04，在 [300 并发素材测试](yh_assets_300_mysql_20261104.md) 后，使用同一编译包、新建隔离 MySQL 库和用户提供的 YH Key，继续覆盖接入规划三个章节中的非生成接口。完成 **180 次网关接口请求**，普通素材管理与上传闭环成功；H5 本人认证失败，视频成功查询/下载缺少已有任务，下载条件请求存在上游限制。因此不能将本轮表述为“所有接口全部验收通过”。

配套：[完整脱敏记录](yh_non_generation_mysql_20261104.json)。本轮没有调用任何视频生成接口，没有修改业务代码。

## 环境和方式

- 完整网关二进制版本 `yh-load300-20261104`；SHA-256 为 `8a822ccaa2cca09b0f125f4a66f54470d4ab71329a09009ffc539ead2f83787a`，与 300 并发测试一致。
- 本地 MySQL `5.7.43-log`，独立库和数据库账号，连接池上限 30。测试服务仅映射 `127.0.0.1:19105`，没有启用自动渠道测试。
- 两个独立网关用户用于归属隔离；一个 `seedance-yh` 渠道，Base URL 为 `https://www.yhapiplatform.com/v1`。
- 主要使用官方 `POST /?Action=...&Version=2024-01-01`，另外测试 REST CRUD 和查询/列表兼容入口。素材使用公开图片、已有的 5 秒视频文件及 3 秒音频文件；上传视频文件不涉及视频生成。
- 180 次请求包含轮询、错误输入和预期的拒绝响应，不包括初始化管理接口、SQL 检查，以及用于对照下载行为/确认删除的 6 次上游直连读取。

| `POST /v1/yh/assets/uploads` | 同步、旧异步、有效批量均成功；同步直接 Active，异步/批量轮询至 Active；无效参数及回调配置明确拒绝 |
| `GET /v1/yh/assets/uploads/{id}` | 返回真实素材 ID，能通过普通 GetAsset 查询；跨用户、误把任务句柄当素材、组删除后查询均被拒绝 |
| `CreateVisualValidateSession` | 成功生成真实 H5 链接和本地查询句柄；CallbackURL 返回 400 |
| `GetVisualValidateResult` | 未完成时 409 `ValidationPending`、`Retry-After: 2`；跨用户和未知句柄 404。本人在手机认证失败，未验证成功关联 |

## 正常与失败素材

- 普通新异步上传共 5 条有效注册（3 张图片、1 个已有视频文件、1 个音频文件），全部 Active。
- 旧同步、旧异步和两张有效图片的批量上传均成功，返回的真实素材可继续 GetAsset。
- 一条刻意不存在的图片 URL 在创建时即被上游返回 HTTP 500，错误为 `InvalidParameter.DownloadFailed`。网关正常转成官方错误包装，没有得到可轮询的素材 ID。
- 一张有效图片加一个无效 URL 的混合批次最终整体 Failed，两条明细均带“素材处理失败”。这是本次供应商实际行为，不能宣称上游保证批次部分成功。
- 空 urls、url/urls 同时指定、批量同步模式、callback_url/callback_secret、未知筛选字段以及未开放的组转移 Action 均明确拒绝。

## 下载限制与初始预期差异

| 场景 | 网关实测 | 对照与结论 |
| --- | --- | --- |
| 越界 Range | HTTP 200，全文件 82,429 字节 | 直连上游同样返回 200，文件 SHA-256 一致。不能断言真实上游会返回 416 |
| `If-Range` 匹配 | HTTP 206，64 字节 | 匹配场景通过 |
| `If-Range` 不匹配 | HTTP 206，仍返回 64 字节 | 直连上游结果相同，确认供应商忽略该条件。当前透传不能保证基于 If-Range 的安全断点续传语义 |
| 非所属项目查询素材 | HTTP 404 | 在归属校验阶段已被拒绝，早于后端参数校验；复查仍为 404 |
| 不存在的视频任务 | HTTP 400 `task_not_exist` | 三个查询入口一致，符合现有网关任务查询错误处理；复查通过 |

原始脚本保留 **173 个通过断言、7 个初始断言差异**，不修改历史记录以制造全通过结果。其中 5 个是预期状态码假设不符（无效 URL、非所属项目、3 个视频查询入口），另 2 个为上表的上游下载行为。配套 JSON 保留原始响应、后续复查与上游对照。`If-Range` 不匹配仍返回部分内容的限制没有通过网关代码修正。

## H5 实际结果

本次链接经编译网关创建后交由用户在手机操作。用户反馈“认证失败”，随后明确不再重试。网关一直未发现本次会话对应的真人组，返回 409 待完成；供应商文档未提供认证失败详情查询接口，不能据此判断手机认证失败原因。

MySQL 检查确认创建了一个本地会话，状态元数据中没有保存原始查询句柄或 H5 链接。未获得真实认证成功组，故真人组关联成功、真人素材上传/FaceMismatch、真人专用删除的真实闭环仍未验收；既有 Mock 结果不替代本轮验收。
