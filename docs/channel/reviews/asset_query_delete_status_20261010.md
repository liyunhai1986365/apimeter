# 素材查询与删除并发时的响应

核对日期：2026-10-10。本次修正查询返回与本地撤销归属之间的竞态，不修改数据库结构。

## 官方依据

- [GetAsset：查询素材资产信息](https://docs.volcengine.com/docs/82379/2318274)：查询上传失败的素材时，接口可能仍返回 HTTP 200，通过 `Result.Status=Failed` 及 `Result.Error.Code/Message` 表达处理失败。
- [DeleteAssetGroup：删除素材资产组](https://docs.volcengine.com/docs/82379/2341606)：成功返回 HTTP 200、`Result={}`；删除组会删除组内素材，素材较多时操作可能耗时。

本轮取得上述两页官方正文，均未规定查询与删除并发时固定返回什么状态。其他错误码页面未取得可核实的正文；不能据此断言官方对已删除素材一定返回 404，也不能把素材处理失败的 HTTP 200 当作素材不存在的返回约定。未调用生产环境或真实供应商做删除实测。

## 网关行为

查询已经通过归属校验并发往上游，但响应抵达网关前，本地归属可能已被另一个删除请求撤销。此时：

- 上游返回成功：保留上游状态与查询结果；本地只放弃被撤销的归属补齐，并跳过后续 TgxMaas 别名保存，不把成功改成网关 404 或 502。
- 上游返回错误：保留其 HTTP 状态、错误码、错误信息及 RequestId；包括 HTTP 200 中的业务错误。
- 删除完成后发起的新请求：继续执行本地归属校验。网关的 `asset_not_found` 404 属于访问控制结果，不代表已经请求上游，也不代表官方返回了 404。

仅对查询中的明确归属撤销错误采用上述处理。所有者或项目/组元数据冲突、数据库异常，以及上游已接受但本地登记失败的创建，仍走各自的错误处理。

## 验证范围

回归覆盖官方 Action 与 REST 入口、火山官方与 TgxMaas 适配器、单素材删除、整组删除、查询素材组、迟到的新别名、素材 `Failed` 状态及上游错误响应。断言查询不重发、状态与错误不改写、归属和别名不复活、后续请求无法绕过访问控制。

MySQL 5.7.43 隔离库验证及 SQLite 功能回归均通过，包含 40 个删除竞态场景和历史认领、用户隔离、元数据冲突、上游状态透传回归。日志保存在 `/tmp/apimeter-lock-review-20261010/mysql-status-alignment.log` 和 `sqlite-status-alignment.log`。

测试中的 200/400/404/503 是人为设置的上游响应，用于验证透传，不能作为官方实际返回这些状态的证据。本次没有重新进行 1000 素材压测，之前压测仍存在的健康检查 503 风险没有因此消除。
