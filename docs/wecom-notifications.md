# 企业微信群机器人通知

系统级告警和个人通知均支持选择 Webhook 消息格式：**通用 JSON** 或 **企业微信群机器人**。

## 配置群机器人

在企业微信群中添加群机器人，复制它提供的完整地址，格式为：

```text
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的机器人key
```

选择“企业微信群机器人”后，系统发送企业微信 Markdown 消息。机器人地址包含凭据，请勿公开。

## 系统级告警

进入 **系统设置 → 运营 → 监控与警报**（`/system-settings/operations/monitoring`）：

1. 开启全局 Webhook 告警。
2. Webhook 格式选择 **企业微信群机器人**，将机器人完整地址填入 Webhook URL。此时 Secret 输入框禁用，群机器人使用 URL 中的 `key` 验证身份。
3. 设置模型错误、渠道测试失败的检测条件、检查间隔和重复通知抑制时间，保存。
4. 如需验证，可点击“发送测试告警”。该操作会实际发群消息，当前测试内容取自最近一条错误日志；没有错误日志时无法发送。

全局 Webhook 接收模型错误、渠道测试失败的定时汇总，以及渠道自动禁用时的即时通知。是否产生告警仍取决于对应检测、自动禁用规则及日志是否启用。

## 管理员及用户个人通知

进入 **个人设置 → 设置与偏好**（`/profile`）：

1. 通知方式选择 **Webhook**。
2. Webhook 格式选择 **企业微信群机器人**，填入机器人完整地址，Webhook Secret 无需填写。
3. 保存设置。

超级管理员的渠道停用、恢复及手动批量测试完成通知会使用这一设置。其他用户的额度不足提醒也可通过此方式发送。管理员还可开启“接收上游模型更新通知”。余额耗尽预测仍固定通过邮件发送。

如果超级管理员个人通知和全局告警填写了同一个群机器人，渠道自动停用时可能收到两条消息，分别来自这两个入口。

## 兼容行为

- 自动替换通知中的数值占位符，将邮件模板的换行、列表和链接转换为群内可读内容。
- Markdown 正文限制为 4096 字节，超长内容按 UTF-8 字符边界截断并添加提示。
- 除 HTTP 状态外，还检查企业微信返回的 `errcode`；业务错误、无效响应或缺少错误码均视为发送失败，并由调用方记录错误。此次兼容不新增发送重试机制。
- 直连与 Worker 转发均支持上述消息格式和返回值检查。
- 选择“通用 JSON”时，始终发送原有 JSON 字段和签名；选择“企业微信群机器人”时，始终发送企业微信格式并检查 `errcode`，也可用于兼容企业微信协议的中转地址。
- 选择的格式优先于地址。旧配置没有格式字段时，暂按地址识别以保留原有行为；页面会显示识别结果，保存后固定使用所选格式。
- 系统配置字段为 `webhook_setting.format`，个人设置字段为 `webhook_format`，取值为 `generic` 或 `wecom`。
